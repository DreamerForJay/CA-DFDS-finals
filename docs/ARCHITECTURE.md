# CA-DFDS 整體架構與方法說明（2026-11-16 更新）

給教授、學長、同學和協作 AI：說明 CA-DFDS 是什麼、遮罩從哪裡來、整個流程怎麼走，以及和其他方法的公平比較。

## 1. 一句話說明

CA-DFDS（Color-Aware Depth From Defocus with Segmentation）：用**一台相機、一張照片**估車距。

- 相機設定：大光圈 f/1.4、對焦在 15 m（後對焦）。
- 原理：1–7 m 內，車越近越模糊。
- 作法：在**車輛遮罩**內量測 **CIECAM02 感知色彩空間**的清晰度，再用事先擬合的**校正曲線**換算成距離。

## 2. 流程圖

```
           ┌─────────────── 離線（做一次）────────────────┐
校正集影像 │ 白／灰／黑車，1.0–7.0 m，每 0.5 m，各 10 張     │
 + 遮罩 ──▶│ 每張算清晰度 σ → 每個距離取平均 → 擬合二次曲線 │──▶ 校正曲線 d = c2·σ² + c1·σ + c0
           └──────────────────────────────────────────────┘     （results/calibration_methods.json）

           ┌──────────────────────────── 線上（每張影像／影片每一格）────────────────────────────┐
輸入影像 ─▶│ ① 車輛遮罩 ─▶ ② 前處理 ─▶ ③ 色彩轉換 ─▶ ④ 清晰度 σ ─▶ ⑤ 查校正曲線 │─▶ 距離 (m)
(f/1.4)    │  手繪／YOLO→SAM   3×3 高斯     CIECAM02 J,a_c,b_c   加權拉普拉斯標準差   二次曲線        │
           └──────────────────────────────────────────────────────────────────────────────────────┘
```

| 步驟 | 內容 | 程式 |
|---|---|---|
| ① 車輛遮罩 | 標出影像中「車」的像素，見第 3 節 | `get_mask.py`（手繪）、`baselines/deep_worker.py`（YOLO→SAM） |
| ② 前處理 | 3×3 高斯濾波；只取遮罩外框範圍計算，結果和整張相同 | `cadfds_core.crop_to_mask` |
| ③ 色彩轉換 | sRGB → XYZ → CIECAM02（D65、L_A = 2000/π×0.2、Y_b = 20、Average），得到明度 J，以及色度 a_c = C·cos h、b_c = C·sin h | `cadfds_core.ciecam_channels` |
| ④ 清晰度 | 三通道各做 3×3 拉普拉斯，加權相加後在遮罩內取標準差 σ（論文式 (5)） | `cadfds_core.sharpness` |
| ⑤ 換算距離 | σ 代入二次校正曲線 | `np.polyval(coef, σ)` |

### CA-DFDS 三個版本差在哪？

三個版本流程完全相同，**只有步驟 ④ 的三個權重 (w_J, w_a, w_b) 不同**：

| 版本 | 權重 (w_J, w_a, w_b) | 由來 | 角色 |
|---|---|---|---|
| **CA-DFDS（本研究）** | **(0.8136, 0.1782, 0.0081)** | 學長以 L-BFGS-B 最佳化（論文採用） | **主方法** |
| CA-DFDS 重新最佳化 | (0.9434, 0.0566, 0) | 2026-11-15 以論文式 (5) 在現有校正集重新最佳化 | 檢查權重是否還有改善空間 |
| CA-DFDS 只用 J | (1, 0, 0) | 不最佳化，只用明度 | 消融對照：色度 a_c、b_c 有沒有幫助 |

- 權重越偏向 J，代表色度資訊越不重要。
- 現有資料上，重新最佳化後的權重幾乎等於只用 J，兩者 RMSE 也幾乎相同（0.314 對 0.313 m），都比論文權重（0.337 m）好一點。
- 換句話說，在目前這批資料上，色度通道的貢獻不明顯。這和黑色校正資料在 2026-07-31 重新產生有關（[LAB_REPORT_2026-11-15.md](LAB_REPORT_2026-11-15.md) 第 4 節），需由學長、教授確認。
- **CA-DFDS 和灰階 DFD 的差別**：灰階 DFD 用 0.299R + 0.587G + 0.114B 灰階影像算清晰度，沒有色彩感知轉換。

## 3. 遮罩是怎麼來的？

### 3.1 目前實驗用的遮罩：學長手繪

- **工具**：`Carla-0.10.0-Win64-Shipping/get_mask.py`（OpenCV 小程式）。
  - 開一張影像，用滑鼠左鍵把車塗出來，按 `s` 存成 `T<n>.npy`（布林陣列，True = 車）。
  - `check_mask.py` 把遮罩疊回原圖檢查。
- **一個距離一份遮罩，各車色共用**：CARLA 場景中，各顏色的消防車停在完全相同的位置，只換車身顏色，所以同一距離的遮罩可以共用。已驗證各色遮罩完全相同（IoU 1.00）。
  - 測試集：`datas/firetruck_black/Test_dataset_Focus1500cm_f1.4_f22.0_mask/T1–T13.npy`。T13 只在資料夾中，評估只用到 T12。
  - 校正集：`datas/training/Training_dataset_mask/T1–T13.npy`。
- 論文（表 8、19 色、demo 影片）的數字都是用這份手繪遮罩算的。

### 3.2 實際道路上沒有手繪遮罩 → 全自動遮罩（2026-11-16 實作）

實際應用時不可能每台車都人工畫遮罩，所以要自動產生。

- **YOLO** 是物件偵測：告訴你「車在哪裡」，輸出**矩形框**。
- **SAM** 是分割：給它一個框，切出框內物體的**像素輪廓**。
- CA-DFDS 需要像素輪廓，因為矩形框裡會混到路面和背景，會污染清晰度。所以兩者要串起來用：

```
影像 ─▶ YOLO11m 偵測 car/bus/truck ─▶ 取最大的框（通常是最近的前車）─▶ SAM ViT-B 依框分割 ─▶ 遮罩
          │ 偵測不到時
          ├─▶（影片）沿用前一格的框，放大 5% ─▶ SAM（追蹤）
          └─▶（單張）近距離前車假設：整幅畫面框、中下方框各跑一次 SAM，取分數高者
```

**為什麼需要後備策略**：

- 2.7 m 以內車尾佔滿畫面，看不到車輪和車輛外形，YOLO 認不出是車。
- 實測 YOLO 偵測率：1.2–2.7 m 幾乎 0%，3.2 m 50%，3.7 m 以上 100%。
- 用近距離前車假設補上這段，480 張全部都能產生遮罩。

**全自動遮罩品質（480 張，與手繪遮罩比較）**：

| 來源 | 張數 | IoU 平均 | IoU 最低 |
|---|---|---|---|
| YOLO → SAM | 310 | 0.925 | 0.893 |
| 近距離後備 → SAM | 170 | 0.873 | 0.660 |
| 全部 | 480 | 0.906 | 0.660 |

時間：YOLO 約 13 ms + SAM 約 105 ms（RTX 5080）。

- **影片輸入**：GUI 選「影片」並選「自動偵測」後，按播放就會逐格自動偵測和估測，**不需要人工拉框**。
- 「框選＋SAM」只是讓人手修正框的工具。

## 4. 和其他方法比較（2026-11-16，同一批 480 張）

**設定**：

- 測試集：紅、綠、藍、黑四色消防車，1.2–6.7 m（T01–T12），每個距離 10 張，共 480 張。每張影像各自估測。
- 所有方法使用相同影像、相同遮罩。
- 深度模型取遮罩內深度的中位數，並給定相機內參 fx = 1137.8 px。
- **公平比較**：論文原本讓深度模型直接輸出、不校正。這次另外用**和 CA-DFDS 相同的校正集**（白、灰、黑 1.0–7.0 m，390 張），對深度模型擬合**線性校正** d = a·預測 + b。
  - UniDepth：d = 0.910·預測 − 1.43 m，R² 0.896。
  - Depth Pro：d = 1.183·預測 − 0.16 m，R² 0.909。
  - CA-DFDS 的二次曲線 R² 為 0.942。

### 4.4 解讀（給教授報告時請照實說明）

1. **不校正時**，CA-DFDS 比 UniDepth 準 5.6 倍、比 Depth Pro 準 2.6 倍。但這是因為深度模型在 CARLA 合成影像上有系統性偏差（UniDepth 平均高估 1.83 m）。
2. **公平比較（深度模型也用同一校正集做線性校正）時**：
   - UniDepth 降到 0.357 m，和 CA-DFDS（0.337 m）、灰階（0.362 m）在同一水準；黑色車上 UniDepth 甚至較好（0.405 對 0.468）。
   - Depth Pro 仍較差（0.751 m）。
   - **所以「CA-DFDS 大幅勝過深度模型」這個說法不成立**，應改為「準確度相當，但各有擅長的距離」。
3. **兩類方法互補**：
   - 失焦法（CA-DFDS、灰階）在 **1.2–3.7 m 近距離**明顯較準。
   - UniDepth 在 **4.2–6.7 m** 較準。
   - 原因：越遠越接近 15 m 對焦距離，模糊訊號變弱；深度模型則在看得到整台車時較準。
   - 這支持「近距離用 CA-DFDS、遠距離融合深度模型」的設計方向。
4. **CA-DFDS 的其他優勢**：
   - 可解釋（σ 有物理意義）。
   - 不需 GPU、不需大型預訓練模型。
   - 校正只需要少量影像。
5. **CA-DFDS 對比灰階**：整體較好（0.337 對 0.362），優勢在中遠距離（3.7–5.7 m）和藍、黑色車；近距離（≤ 3.2 m）反而是灰階較準。
6. **全自動遮罩可行**：
   - 全自動遮罩下 CA-DFDS RMSE 反而略降（0.337 → 0.310 m），推測是 SAM 輪廓比手繪更貼合車身、少混背景。
   - 注意：校正曲線仍是用手繪遮罩的校正集擬合；若校正集也改用自動遮罩，結果可能再變。
7. 時間：CA-DFDS 是 CPU 單執行緒、未優化；只算遮罩外框範圍時約 0.5–2.9 s，主要花在 CIECAM02 轉換，可改用 GPU 實作加速。深度模型的時間是 RTX 5080 上只計推論。
8. 數據警示：黑色校正影像於 2026-07-31 重新產生，論文校正曲線無法以現有資料重現。以上數字全部基於現有資料。
